# Virtual Vadodara Railway Station: An Interactive 3D Visualization

An interactive 3D visualization of Vadodara Railway Station, developed using Unity Engine and recreated as a browser-based application with HTML, CSS, JavaScript, Three.js, and WebGL.

## Project Overview

This project presents a virtual representation of Vadodara Railway Station for the Computer Graphics and Image Processing (CGIP) course. It aims to help visitors, students, and other users explore the station layout, platforms, entrances, and facilities through an interactive 3D scene.

The model was guided by real-world station photographs, Google Earth satellite imagery, and approximate measurements of major station elements. It is intended to communicate the station layout and may not match every real-world detail or dimension exactly.

## Development Approach

The project was developed in two stages:

1. **Unity Engine – Initial 3D modelling:** Major structures and scene objects were developed, including the station building, platforms, railway tracks, foot overbridges, surrounding structures, roads, parking areas, gardens, and vehicles.
2. **HTML + Three.js – Interactive browser application:** The scene was recreated as a browser-based interactive application using HTML, CSS, JavaScript, Three.js, and WebGL.

## Main Features

- Six platforms and seven railway lines, including a bypass line
- Station building, concourse, waiting room, booking areas, and ticket counters
- Railway platforms, tracks, canopies, foot overbridges, and stairs
- Front and back entrance areas, roads, parking, gardens, and nearby surroundings
- Animated moving train
- Walk mode and fly mode
- Day and night modes
- Direct camera views for platforms 1–6
- Minimap and FPS counter
- Station signs and facility indicators
- Procedurally generated textures

## Technologies Used

- **Unity Engine** – initial 3D modelling
- **HTML** – application structure
- **CSS** – interface styling
- **JavaScript** – application logic and interactions
- **Three.js** – browser-based 3D graphics
- **WebGL** – graphics rendering in the browser

## Computer Graphics Concepts

The project demonstrates 3D geometry and modelling, material and texture mapping, procedural texture generation, lighting and shadows, animation, camera positioning, and interactive navigation.

## Real-World Reference and Modelling

The station layout was studied using real-world photographs and Google Earth satellite imagery. Approximate measurements and visual references guided the placement and proportions of platforms, railway lines, entrances, and other major structures. These references helped create a useful overall representation, although the model is not claimed to be an exact engineering replica.

## Performance

The browser application has shown approximately **50–70 FPS** in observed use. Actual performance can vary depending on the computer, browser, and graphics hardware.

## How to Run the HTML Version

1. Open the folder containing the HTML application.
2. Open the main `.html` file in a modern web browser such as Google Chrome.
3. Keep an internet connection available if the application loads Three.js from a CDN.
4. Use the on-screen controls or help panel to explore the scene.

## Limitations and Future Scope

The current model may not perfectly match the real station in every detail. Future work may add more details and station information, improve accuracy using additional references, and support use on Android, iOS, and Windows.

## Purpose

The project demonstrates the application of computer graphics concepts in creating an interactive virtual environment. It can help users gain a general understanding of the station layout and locate platforms, entrances, and facilities.
